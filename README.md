# Local SEO By Ankit Rawat

WordPress plugin that outputs LocalBusiness JSON-LD (and optional WooCommerce product structured data) from a settings screen.

It does **not** connect to Google Business Profile, import reviews, or change canonical URLs.

See `readme.txt` for installation, upgrade notes from 3.3, and the full feature list. Store OfferCatalog JSON-LD defaults to the front page, home, and WooCommerce shop; customize with `local_seo_by_ankit_rawat_embed_store_catalog`.

Maintainers: `php bin/package.php` builds a production ZIP (see `docs/PACKAGING.md`).
